# VivaCalif-Sales-Analysis
This Report contains Sales Analysis Project Using EXCEL
## Overview

This project is an **interactive Excel Sales Dashboard** built to analyze sales performance and business KPIs using raw sales data.
The dashboard transforms raw data into meaningful insights through **Pivot Tables, Charts, and Slicers**, enabling faster and better business decision-making.

## Objective
The objective of this dashboard is to analyze sales data and monitor business performance through interactive visualizations. The dashboard helps identify sales trends, top-performing products, customer demand patterns, and regional performance to support better business decisions.

## Tools Used
- Microsoft Excel  
- Pivot Tables & Pivot Charts  
- Slicers & Filters  
- Data Cleaning & Formatting  
- Basic Data Analysis Techniques  

## Key Metrics
- Total Quantity
- Total Orders
- Total Amount
- Average Rating
- Average Days to Deliver

## Dashboard Features
✔️ Interactive Excel dashboard for sales performance analysis  
✔️ KPI tracking (Total Sales, Profit, Orders, Revenue)  
✔️ Region-wise and category-wise analysis using Pivot Tables  
✔️ Monthly and yearly trend analysis  
✔️ Top-performing products and customer insights  
✔️ Dynamic filters using Slicers (Region, Product, Category, Time)  
✔️ Drill-down capability for deeper insights  
✔️ Clean and professional dashboard layout  
✔️ Automated updates using Pivot Table refresh  
✔️ User-friendly design for quick business reporting  

## Business Insights
- Identified top-performing products and categories  
- Analyzed monthly and seasonal sales trends  
- Discovered high-performing regions  
- Evaluated overall business performance using KPIs  
- Improved understanding of customer purchasing patterns
